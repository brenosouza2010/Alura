# Guia: Zerar Silksong — Alma de Aço

Projeto criado para a unidade Start by Alura: páginas web com HTML semântico, CSS (Flexbox), JavaScript (DOM), interatividade e acessibilidade.

Como usar
1. Coloque os arquivos em uma pasta.
2. Abra `index.html` no navegador (ou publique em um server estático).
3. Use os botões + / − para marcar chefes vencidos. O estado é salvo no localStorage.
4. Use o botão "Tema" para alternar entre claro/escuro.

O que esse projeto demonstra (requisitos da unidade)
- HTML semântico: header, nav, main, section, article, footer, aside.
- CSS com Flexbox e responsividade (media queries).
- JavaScript para manipular o DOM: criar elementos, atualizar contadores, eventos, armazenamento local.
- Funcionalidades dinâmicas: contadores, lógica condicional (verifica conclusão e mostra modal).
- Acessibilidade: skip link, aria-labels, aria-live para contadores, foco no modal, prefers-reduced-motion.
- UX: layout limpo, feedback imediato, persistência de preferências.
- Estrutura de arquivos: separação clara entre HTML, CSS e JS.
- Produção colaborativa: inclua nomes/contribuições aqui (arquivo README) e referencie fontes.

Boas práticas de autoria e referências
- Autor base: Breno Souza (exemplo). Em trabalho colaborativo, adicione seu nome e descrições de contribuções.
- Referências gerais: informações públicas sobre Hollow Knight e Silksong (Team Cherry), wikis e guias de comunidade. Ao usar conteúdo de terceiros, cite sempre a fonte original e não reproduza material protegido sem permissão.

Acessibilidade e ética
- Evite automações que prejudiquem outros jogadores.
- Seja transparente sobre fontes e contribuições.

Contribuições
- Para adicionar chefes ao contador, edite `script.js` e inclua novos objetos no array `bosses`.
- Para traduzir ou expandir o guia, modifique `index.html` com novas seções (use HTML semântico).
